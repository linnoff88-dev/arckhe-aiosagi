Por que aprender AIOS?

AIOS é o projeto da AGI Research (Rutgers) que embute LLMs no sistema operacional. Resolve scheduling, context switch, memória, storage e tool management para agentes — problemas que cada framework hoje tenta resolver sozinho. Repo oficial com mais de 4k stars, paper aceito na COLM 2025, e ecossistema com Cerebrum (SDK), A-MEM (memória), LiteCUA (computer-use) e LSFS (filesystem semântico).

🧩

Kernel especializado

LLM Core, Memory Manager, Storage, Tool Manager, Scheduler e Context Manager projetados para o ciclo de vida do agente — não adaptados de SO genérico.

🔌

SDK Cerebrum

Plataforma para desenvolver, publicar e distribuir agentes que conversam com o kernel via syscalls — local ou remoto.

🖥️

Computer-use ready

Arquitetura LiteCUA com VM Controller + MCP Server para agentes que operam interfaces gráficas em sandbox.

Quem mantém o AIOS?

Spoiler: não existe curso pago formal sobre AIOS até hoje. O ecossistema é totalmente acadêmico e comunitário:

Fontes oficiais

  • • AGI Research (Rutgers) — laboratório responsável
  • • Repositório — github.com/agiresearch/AIOS
  • • Docs — docs.aios.foundation
  • • Discord — comunidade aberta
  • • Papers — AIOS (COLM 2025), Cerebrum (NAACL 2025)

Projetos do ecossistema

  • • Cerebrum — SDK oficial de agentes
  • • LiteCUA — computer-use agent
  • • A-MEM — memória agêntica (paper 2025)
  • • OpenAGI — framework de agentes compatível
  • • INEMA.CLUB — este curso em português 🧠
